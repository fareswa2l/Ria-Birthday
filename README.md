# Birthday Surprise Website 🎀

A small, responsive birthday website made with plain HTML, CSS, and JavaScript. No frameworks or build tools needed.

## Preview it on your computer
1. Download and extract `birthday-surprise.zip`.
2. Open the extracted folder.
3. Double-click `index.html`. It should open in your browser.

## Publish it free with GitHub Pages
1. Sign in to [GitHub](https://github.com/).
2. Click **+** in the top-right corner → **New repository**.
3. Name it `birthday-surprise` and set it to **Public**.
4. Create the repository.
5. On the repository page, click **Add file** → **Upload files**.
6. Upload these three files from this folder: `index.html`, `style.css`, and `script.js`. You can upload `README.md` too.
   - Important: upload the files themselves to the repository's root, not a nested `birthday-surprise` folder.
7. Click **Commit changes**.
8. Open **Settings** → **Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select branch **main** and folder **/(root)**, then click **Save**.
11. Wait a minute or two. Refresh the Pages section; GitHub will show your website URL, usually:
    `https://YOUR-USERNAME.github.io/birthday-surprise/`
12. Open the URL to test it, then send that link to her.

## Personalize it first
- In `index.html`, change the title and text to make the message more personal.
- To put her name in the main heading, replace `Beautiful.` with her name, for example `Sarah.`.
- The gift button opens a surprise message. You can edit that message in the `modal-message` paragraphs.
- If you change any file after publishing, commit the changes and GitHub Pages will update the site.

The fonts are loaded from Google Fonts, so the site uses fallback fonts if the internet is unavailable.
